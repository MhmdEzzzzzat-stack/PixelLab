# PixelLab – Advanced Image Processing Lab

PixelLab is a desktop application built with Python that provides a graphical interface for loading, previewing, converting, and saving images.

The application allows users to upload an image from their device or load a built-in demo image, choose an available conversion, preview the original and converted images, and save the result.

## Current Features

- Desktop graphical interface built with CustomTkinter.
- Load images in PNG, JPG, JPEG, WEBP, and BMP formats.
- Load a built-in demo image.
- Convert RGB images to Grayscale.
- Convert RGB images to CMY using color inversion.
- Preview the original image and the converted result.
- Save the converted image to the device.

## Technologies

- Python
- CustomTkinter
- Pillow

## Run the Application

Install the required packages:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python main.py
```
